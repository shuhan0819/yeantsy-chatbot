# 演慈聊天機器人（Yeantsy Chatbot）

> 基於 GPT-4o-mini 的日常生活輔助聊天機器人，專為演慈服務使用者設計，提供天氣、交通、飲食、娛樂、醫療等生活問答服務。

---

## 關於演慈聊天機器人

演慈聊天機器人（生活小幫手）是一款為**演慈服務使用者**量身打造的 AI 聊天助手。  
語氣溫和親切、回答簡單易懂，讓使用者可以輕鬆用文字或語音提問日常生活中的各種問題。

- **開發目的**：支持自立生活，提供便利的日常資訊查詢
- **服務對象**：演慈的服務使用者及相關工作人員
- **技術核心**：OpenAI GPT-4o-mini、Whisper 語音辨識、Streamlit 前端框架

---

## 功能介紹

### 即時天氣查詢
- 串接中央氣象署（CWA）開放資料 API，提供全台各縣市天氣預報
- 可詢問：今天天氣怎麼樣、需要帶雨傘嗎、今天適合洗衣服嗎、會不會有颱風…等
- 自動偵測問題中的城市名稱（例如「高雄天氣」），預設為臺北市

### 動態交通導航
- 說「我想去 ○○ 要怎麼去」，自動產生 Google Maps 導航連結
- 捷運路線查詢：引導使用 Google Maps 規劃最佳路線
- 公車即時動態：直接連結台北市公車動態查詢系統

### 題庫問答
涵蓋以下七大生活類別，語意比對後給出對應答案：

| 類別 | 範例問題 |
|------|----------|
| 衣著 | 天氣冷該穿什麼？下雨天可以穿拖鞋嗎？ |
| 飲食 | 怎麼吃才健康？外食要怎麼選？ |
| 交通 | 公車還要等多久？捷運怎麼搭？ |
| 娛樂 | 台北推薦什麼景點？有什麼電影推薦？ |
| 醫療 | 為什麼要吃藥？什麼時候要看醫生？ |
| 人際互動 | 跟別人吵架怎麼辦？想拒絕別人怎麼說？ |
| 理財 | 悠遊卡要怎麼儲值？如何存零用錢？ |

### MD 資料庫查詢
- 特定問題（景點、電影、動漫、劇集、血型等）會從本地 `.md` 知識庫中抓取內容
- 知識庫可自行擴充，對應題目由 `總題目單.xlsx` 管理

### 星座查詢
- 輸入日期即可查詢對應星座，例如「8/18 是什麼星座？」
- 本地計算，不需呼叫 GPT，回應速度快

### Google Sheets 對話記錄
- 每筆對話（使用者問題、機器人回覆、分類）自動記錄到指定 Google 試算表
- 方便工作人員追蹤使用狀況與常見問題

## 使用方式

### 文字輸入
1. 在畫面下方的輸入框輸入問題
2. 按下 Enter 送出，稍候片刻即可看到回覆

### 語音錄音輸入
1. 點擊輸入框旁的麥克風圖示開始錄音
2. 說完後停止錄音，系統會自動透過 Whisper 將語音轉為文字
3. 辨識完成後自動送出並取得回覆

### 快速提問按鈕
首次開啟時，畫面提供四個常見問題的快速按鈕，點擊即可直接發問。

### 重置對話
- 點擊右上角的「重置」按鈕可清空目前對話
- 對話閒置超過 5 分鐘（300 秒）將自動重置，倒數計時顯示於畫面右上角

## 注意事項

### 安全護欄
當使用者訊息涉及以下內容時，機器人不會提供建議，而是立即引導聯繫專業人員：

- 負面情緒（心情差、沮喪、好累…）
- 自傷或傷人念頭
- 輕生相關語句
- 精神症狀（幻聽、被監視感…）
- 嚴重睡眠問題
- 衝動控制困難

觸發後回覆：「建議與 Karen、Doris、Amy 聊聊」

此設計優先保護使用者安全，任何其他功能均不覆蓋此規則。

### 隱私說明
- 對話內容會記錄至 Google Sheets，供服務團隊了解使用狀況
- 記錄內容包含：時間戳記、使用者問題、機器人回覆、問題分類
- 不記錄個人身份資訊

### 其他注意事項
- 本機器人不回答政治爭議、成人內容、危險操作等不適當問題
- 天氣資料來源為中央氣象署，每 30 分鐘更新一次快取
- 語音辨識預設為繁體中文

## 環境設定

### 必要套件
```bash
pip install streamlit openai gspread google-auth pandas openpyxl streamlit-autorefresh
```

### secrets.toml 設定
在 `.streamlit/secrets.toml` 填入以下設定：

```toml
OPENAI_API_KEY = "sk-..."
CWA_API_KEY    = "your-cwa-api-key"
GSHEET_URL     = "https://docs.google.com/spreadsheets/d/..."

[gcp_service_account]
type = "service_account"
project_id = "..."
private_key_id = "..."
private_key = "..."
client_email = "..."
```

> 請將 `secrets.toml` 加入 `.gitignore`，避免金鑰外洩。

### 啟動方式
```bash
streamlit run yeantsy_streamlit_chatbot.py
```
